# Lời giải theo phương pháp

> **Dành cho giảng viên.** Có thể phát cho học viên **sau khi** đã chấm bài.

Các file ở đây giải thích **cách làm**: chạy lệnh nào, đọc cột nào, suy luận
ra sao, và học viên thường sai ở đâu. Chúng dùng được với **mọi mã đề**.

**Đáp án cụ thể** (IP, mật khẩu, giá trị setpoint của từng mã đề) không nằm ở
đây. Sinh bằng:

```bash
python3 tao-de/make_lab.py --seed 1001 --out de-1001/ --dap-an
```

Ví dụ minh hoạ trong các file dùng mã đề **101**; số liệu của bạn sẽ khác.
